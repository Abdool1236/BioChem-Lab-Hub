# 🧪 BioChem Lab Hub

## Biochemistry Calculator & Study Tools

**Calculate • Learn • Explore Biochemistry**

BioChem Lab Hub is a web-based educational platform designed to help Biochemistry students, laboratory trainees, researchers, and science learners perform common biochemical calculations and learn important Biochemistry concepts in one place.

The project combines **Biochemistry calculators, study topics, formulas, search tools, and quizzes** in a simple and mobile-friendly web application.

---

## 🌟 Features

### 🧮 Biochemistry Calculators

BioChem Lab Hub provides a collection of useful calculators for laboratory and academic work, including:

- Molarity
- Dilution
- Molecular Weight
- Molality
- Normality
- pH
- pOH
- Buffer / Henderson-Hasselbalch
- Beer-Lambert Law
- Enzyme Activity
- Specific Activity
- Km & Vmax
- Protein Concentration
- DNA GC%
- DNA Molecular Weight
- DNA Complement
- DNA/RNA Concentration
- DNA Melting Temperature
- A260/A280 Purity Ratio
- Unit Converter
- Percentage Concentration
- Serial Dilution
- RCF Centrifugation
- Protein Molecular Weight
- Amino Acid Calculator
- Absorbance → Concentration
